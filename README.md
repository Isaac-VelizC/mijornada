# Mi Jornada

Aplicación web personal para registrar jornadas de trabajo y pagos.

Permite llevar un control sencillo de los días trabajados desde el último pago, diferenciando jornadas completas, medias jornadas, horas personalizadas y ausencias.

## ✨ Características

* 📅 Registro de jornadas de trabajo
* 💰 Registro de pagos
* 📊 Resumen de días y horas trabajadas
* 💾 Exportación e importación de copias de seguridad
* 📱 Diseño responsive y preparado para PWA
* 🔒 Datos almacenados localmente en el navegador

## 🛠️ Tecnologías

* React
* TypeScript
* Vite
* Tailwind CSS
* Dexie / IndexedDB
* React Router
* date-fns

## 🚀 Desarrollo

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```
